# Программы к статье об обратной задаче теплопроводности

Это программы, входные данные и сохранённые результаты к статье **Initial Temperature Reconstruction Using Physics-Informed Neural Networks: Comparison with Classical Methods**. Подробный иллюстрированный обзор задачи, методов и результатов находится в [основном README](README.md).

**Начните с [README.md](README.md) и [docs/EXPERIMENT_MAP.md](docs/EXPERIMENT_MAP.md).**

- Ноутбуки `00–05`, `07–10` — расчёты статьи; последовательность `08 → 09 → 10` соответствует сильной нелинейной 2D-задаче с QR.
- Модули `inverse_study/` содержат исходные вычислительные реализации.
- `data/` — наблюдения и численные данные; `published_results/` — сохранённые численные результаты для просмотра **без переобучения**.
- `scripts/paper_results.py` выводит результаты сравнений, `scripts/legacy_noise_grid_tables.py` — сохранённые серии по шуму и полным терминальным сеткам.
- **Внимание:** `Run All` в тренировочных ноутбуках запускает полноценное обучение, если нет checkpoint-файлов! Последние намеренно не включены в публичную подборку.

В основном README показаны семь иллюстраций из статьи и дополнительных материалов: архитектура сети, линейная и нелинейная 2D-реконструкция, восстановление разрыва, эксперимент с латунью, влияние шума и плотности датчиков. Исходные графики автора **не перерисованы**. Наборы с исторически другим протоколом наблюдений описаны отдельно от повторных экспериментов.

В линейном 2D-тесте наименьшую ошибку даёт TSVD, в нелинейном 2D-тесте — Fourier PINN с фиксированными весами, на данных латуни среди трёх PINN-вариантов — обычный PINN. Подробные таблицы, число повторений и ограничения сравнений приведены в основном README.

Репозиторий поддерживает [kuznetsovks17](https://github.com/kuznetsovks17). Сведения о происхождении данных, ограничениях воспроизводимости и отсутствии выбранной лицензии сохранены в документации.
