# Программы к статье об обратной задаче теплопроводности

Это отобранные программы, входные данные и компактные результаты **только для статьи об обратной задаче**. Отдельная работа о прямых задачах и признаках Фурье, слоистый материал и 3D-демонстрации сюда не входят.

**Начните с [README.md](README.md) и [docs/EXPERIMENT_MAP.md](docs/EXPERIMENT_MAP.md).**

- Ноутбуки `00–05`, `07–10` — расчёты статьи; последовательность `08 → 09 → 10` соответствует сильной нелинейной 2D-задаче с QR.
- Модули `inverse_study/` содержат исходные вычислительные реализации.
- `data/` — наблюдения и численные данные; `published_results/` — сохранённые численные результаты для просмотра **без переобучения**.
- `scripts/paper_results.py` выводит результаты сравнений, `scripts/legacy_noise_grid_tables.py` — сохранённые серии по шуму и полным терминальным сеткам.
- **Внимание:** `Run All` в тренировочных ноутбуках запускает полноценное обучение, если нет checkpoint-файлов! Последние намеренно не включены в публичную подборку.

Исходные графики автора **не перерисованы**; собранные результаты исследования не переинтерпретированы. Наборы с исторически другим протоколом наблюдений отделены от новых экспериментов.

Перед публикацией на GitHub: выберите лицензию для кода, проверьте право распространения оцифрованных экспериментальных данных и подтвердите сведения для цитирования. Репозиторий на GitHub не создавался автоматически.
